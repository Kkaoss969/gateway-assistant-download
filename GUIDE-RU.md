# Live Assistant (часы) + Gateway Assistant (телефон) — краткое руководство

С часами Amazfit (Zepp OS), Huawei Watch 3 / Watch 4, часами **Wear OS** (Galaxy Watch, Pixel Watch, TicWatch…) или часами Huawei на **HarmonyOS** (Watch 5, Watch 6, Watch Ultimate 2…) вы разговариваете с Gemini, а через приложение **Gateway Assistant** на телефоне Android можете:
управлять умным домом Google, звонить, отправлять, читать и отвечать на сообщения WhatsApp и использовать голос телефона.
Каждый использует свой телефон, свой аккаунт Google и свой ключ Gemini: делиться ничем не нужно.

🌐 Приложения говорят на **русском, итальянском, английском, испанском, французском, португальском (Португалия и Бразилия), болгарском, турецком и немецком**: они сами следуют языку часов и телефона. · *Italiano: [GUIDA.md](GUIDA.md)* · *English: [GUIDE.md](GUIDE.md)* · *Español: [GUIA.md](GUIA.md)* · *Français : [GUIDE-FR.md](GUIDE-FR.md)* · *Português: [GUIA-PT.md](GUIA-PT.md)* · *Português do Brasil: [GUIA-BR.md](GUIA-BR.md)* · *Български: [GUIDE-BG.md](GUIDE-BG.md)* · *Türkçe: [GUIDE-TR.md](GUIDE-TR.md)* · *Deutsch: [GUIDE-DE.md](GUIDE-DE.md)*

## Что нужно
- Телефон Android с приложением **Zepp** и уже сопряжёнными часами
- **Ключ API Gemini** (бесплатный или с балансом для более быстрых ответов): https://aistudio.google.com/apikey
- Приложение **Google** (Ассистент) на телефоне, связанное с вашим Google Home (только для команд умного дома)

## Ключи API
Ключи вводятся **только один раз** в Gateway Assistant → **🔑 Ключи API** и действуют для всех часов; со страницы каждых часов вы передаёте их в Live кнопкой *Отправить ключи на часы* (или при установке).
- **Gemini** (обязательно, бесплатно): откройте https://aistudio.google.com/apikey со своим аккаунтом Google → **Create API key** → выберите или создайте проект → скопируйте ключ (начинается с `AIza` или `AQ.`) и вставьте его в Gateway → *Сохранить ключ Gemini*. У бесплатного тарифа есть дневные лимиты; с небольшим балансом ответы быстрее.
- **Groq** (необязательно, бесплатно): откройте https://console.groq.com/keys, войдите (подойдёт Google) → **Create API Key** → дайте ему имя → скопируйте ключ (начинается с `gsk_`, показывается только один раз) и вставьте его в Gateway → *Сохранить ключ Groq*. Он даёт письменные ответы примерно за 1 секунду.
- Чтобы удалить ключ, удерживайте его кнопку *Сохранить*.

## 1 · Установите Gateway Assistant (телефон)
1. Скачайте APK на телефон: **https://github.com/Kkaoss969/gateway-assistant-download/raw/main/GatewayAssistant.apk**
2. Откройте его и разрешите установку из этого источника, если Android спросит.
3. Откройте **Gateway Assistant** и нажмите **Запустить Gateway**.
4. В списке **Разрешения** нажимайте на каждую строку с ⚪, пока все не станут ✅:
   контакты и звонки · поверх других приложений · отправка WhatsApp (специальные возможности) · чтение WhatsApp (уведомления) · батарея без ограничений.
   ⚠ **Специальные возможности**: на странице Android «Gateway Assistant (отправка WhatsApp)» включите **только первый переключатель вверху** («Вкл.»). **Не включайте** второй, «Быстрое включение Gateway Assistant (отправка WhatsApp)»: это просто ярлык Android, и если он включён, автоматические нажатия (Отправить в WhatsApp, Выключить/Отложить будильник, отправка в Gemini) не работают.
   Если настройка «ограничена»: Настройки → Приложения → Gateway Assistant → меню ⋮ → *Разрешить ограниченные настройки*.
5. Нажмите **Скопировать код** (код канала).

## 2 · Установите Live Assistant на часы
1. В приложении Zepp включите режим разработчика: Профиль → Настройки → О приложении → несколько раз нажмите на логотип Zepp.
2. Откройте **https://kkaoss969.github.io/gateway-assistant-download/**, выберите свои часы и отсканируйте **QR-код** приложением Zepp (Профиль → значок сканирования).
3. В приложении Zepp откройте настройки приложения **Live Assistant** и заполните:
   - **Ключ API Gemini**
   - **Мой город** (погода и местные новости)
   - **Gateway Assistant → Код**: вставьте код, скопированный на шаге 1
   - **Ключ API Groq** (необязательно, бесплатно на https://console.groq.com → *API Keys*): на новости и написанные вопросы ответ приходит примерно за 1 секунду; голосовые вопросы остаются за Gemini
   - **Часто используемые имена** (необязательно): люди, города, команды… они помогают понять правильные имена
   - **Язык приложения**: обычно язык часов; русский выбирается сам, если часы на русском (или выберите **Русский** здесь)

## 3 · Рекомендуется
- **Звонки на часах**: приложение Zepp → Профиль → часы → Настройки приложений → Телефон → *Отвечать на звонки на часах* (и выполните сопряжение Bluetooth).
- **WhatsApp при заблокированном телефоне**: Настройки → Безопасность → Smart Lock / Extend Unlock → *Надёжные устройства* → добавьте часы.
- **Двойной WhatsApp (клон)**: если на телефоне есть второй, клонированный WhatsApp (Samsung Dual Messenger, «Двойные приложения» на других телефонах), текстовые сообщения отправляются, но **голосовые с часов — нет** (WhatsApp открывает чат без звука). Чтобы отправлять голосовые, удалите клон WhatsApp; два аккаунта в одном WhatsApp — не проблема. Gateway отмечает это значком ⚠️ на кнопке отправки WhatsApp.
- **Beeper (экспериментально)**: если вы пользуетесь [Beeper](https://play.google.com/store/apps/details?id=com.beeper.android) с привязанными WhatsApp и Telegram, нажмите *🧪 Beeper* в Gateway и разрешите доступ: текстовые сообщения отправляются без открытия WhatsApp и без специальных возможностей, даже при заблокированном телефоне, а в Telegram можно писать в любой чат. Голосовые по-прежнему идут через WhatsApp.
  Без этого телефон просыпается, а сообщение отправляется, когда вы его разблокируете.
- **Команды умного дома при заблокированном телефоне**: приложение Google → Настройки → Google Ассистент → Заблокированный экран → личные результаты вкл.

**Будильник телефона**: когда он звонит, часы вибрируют и сами показывают кнопки **Выключить** и **Отложить**. Часы узнают время следующего будильника каждый раз, когда вы открываете Live Assistant (и после каждого будильника): если вы создали новый будильник на телефоне, откройте приложение на часах один раз. ⚠ В **режиме сна** или **«Не беспокоить»** часы блокируют сторонние приложения: настройте окончание режима сна / «Не беспокоить» за несколько минут до будильника (Настройки часов → Не беспокоить → По расписанию).

**Gemini Live (проба)**: в приложении Zepp → Live Assistant → Настройки включите **Использовать Gemini Live** (нужен Gateway Assistant 1.65 или новее на том же телефоне). Ответ приходит сразу голосом, без ожидания синтеза речи; если Live не сработает, используется обычный способ.

## Store Gateway: приложения для часов
В Gateway Assistant нажмите **Store** на нижней панели: там наши приложения для ваших часов, сгруппированные по системам (Huawei, Wear OS, Amazfit, HarmonyOS).
- **Live Assistant**: голосовой ассистент с Gemini Live (см. раздел для своих часов ниже).
- **NextUp** (Huawei, Wear OS, Amazfit): полноценный WhatsApp на часах, с чатами, голосовыми, фото, оповещениями и ответами, даже вдали от телефона. При первом запуске выберите, как им пользоваться:
  - **через Gateway**: не занимает место среди связанных устройств WhatsApp; в Gateway должен быть включён *Прямой WhatsApp*. На Amazfit NextUp всегда работает так;
  - **своя привязка**: на телефоне WhatsApp → *Связанные устройства* → *Привязка устройства*, затем отсканируйте код, показанный на часах.
  ⚠ NextUp — не официальное приложение WhatsApp: за его использование номер могут заблокировать. Используйте на свой риск, лучше со вторым номером.
- **NextGram** (Huawei, Wear OS): Telegram на часах, с чатами, голосовыми, фото, стикерами и оповещениями, даже без телефона. При первом запуске отсканируйте код, показанный на часах, Telegram'ом на телефоне (Настройки → *Устройства* → *Подключить устройство*).

**Как установить**
1. Сначала подключите часы на их странице в Gateway, как для Live: **Huawei** с отладкой по Wi-Fi, **Wear OS** с беспроводной отладкой (см. ниже).
2. В Store выберите систему, отметьте приложения и нажмите **Установить выбранные** (или **📲 Установить все**).
3. Gateway скачивает приложения, проверяет, что на них наша подпись, устанавливает их и выдаёт разрешения. Он также передаёт Live ключи и код канала. Окно показывает каждый шаг до **✅ Готово: можно закрыть**.
4. **Amazfit**: нажмите **📷 Показать QR-код** и отсканируйте его приложением Zepp (режим разработчика). **HarmonyOS**: Live устанавливается со страницы ⌚ Часы HarmonyOS, которая подписывает приложение вашим аккаунтом Huawei.

**Обновления**: на главном экране Gateway каждые часы показывают свои приложения: **зелёным**, если они актуальны, и **оранжевым**, если есть новая версия. Нажмите на часы: откроется Store с кнопками **🔄 Обновить** или **🔄 Обновить все**. **🔍 Проверить версии на часах** заново читает, что установлено.

## Часы Huawei (Watch 3, Watch 4)
Для **Huawei Watch 3 и Watch 4** (на базе Android) есть **Live Assistant** с **Gemini Live**: пока вы говорите, вопрос уже идёт в Gemini, а ответ сразу возвращается голосом, обычно за 1-3 секунды. Работает через Wi-Fi или LTE часов, а также только по Bluetooth через Gateway. Устанавливается из **Gateway Assistant**, компьютер не нужен.
1. На часах: Настройки → О часах → несколько раз нажмите на **номер сборки**. Затем в **Параметрах разработчика** включите **Отладку HDC** и **Отладку по Wi-Fi**.
2. Часы и телефон в **одной сети Wi-Fi** (точка доступа телефона тоже подходит).
3. В Gateway Assistant нажмите **⌚ Часы Huawei: установка и диагностика**, введите IP, показанный в *Отладке по Wi-Fi*, и нажмите **Скачать и установить Live Assistant**. В первый раз часы попросят разрешить подключение: нажмите **Всегда разрешать**.
   Gateway передаёт часам код канала и, если отмечено, ваш ключ Gemini; он также исключает приложение из энергосбережения.
4. В Gateway Assistant нажимайте **⚪ Разрешить Bluetooth Huawei**, пока не появится **✅ Bluetooth Huawei: вкл.**: тогда часы работают **без Wi-Fi и LTE**, через Bluetooth телефона.
5. **Нижняя кнопка**: на той же странице нажмите **Нижняя кнопка: открыть Live Assistant**. Нажатие нижней кнопки часов будет открывать Live Assistant, уже слушающий, вместо Celia (*Восстановить Celia* отменяет это).

На часах **шестерёнка** под *Новый чат* открывает настройки (город, подключение Авто/Bluetooth/Интернет, голос, обновления, диагностика); **колёсико** прокручивает страницы. Работают вопросы, голос, погода и новости, умный дом Google, Контакты и WhatsApp, звонки, быстрые команды, напоминания, фонарик, громкость и яркость, шаги и пульс. Голосом можно также менять **DPI экрана** («поставь dpi 280», «сбрось dpi»; от 90 до 400, стандарт 320); в настройках часов есть **Сбросить DPI**, а в Gateway (страница часов Huawei, раздел *DPI экрана*) — **Задать** и **Сбросить (320)**.
**Будильник телефона**: когда он звонит, часы вибрируют и показывают **Стоп** и **Отложить** (даже в ночном режиме, который выключается за минуту до будильника; «Отложить» снова его включает). Работает и с будильниками, поставленными в последний момент: в приложении Здоровье → Устройства → часы → Уведомления включите **Gateway Assistant**.
**Обновления**: Gateway Assistant показывает установленную и новую версию; обновляйте с той же страницы или с часов (Настройки → *Проверить и установить*, с включённой отладкой по Wi-Fi).
**Groq (необязательно)**: на общие вопросы Live отвечает сам; команды (умный дом, звонки, WhatsApp, будильники, погода, новости) выполняет приложение, и с ключом Groq текстовая часть готова примерно за 1 секунду. Бесплатный ключ: https://console.groq.com → *API Keys* → *Create API Key* (начинается с `gsk_`), вставьте его в Gateway → *🔑 Ключи API* → *Сохранить ключ Groq*.
**Диагностика**: она сама приходит в Gateway (страница часов Huawei; с часов также Настройки → *Отправить в Gateway Assistant*). Кнопкой **Поделиться** вы отправляете её текстовым файлом (WhatsApp, Telegram, email) тому, кто вам помогает.
**Открытие двумя встряхиваниями (проба)**: в настройках часов включите *Проба: два сильных встряхивания открывают приложение*. При включённом экране два резких встряхивания подряд открывают Live Assistant, уже слушающий; при постоянно включённом экране датчик выключен для экономии батареи: поднимите руку, чтобы снова включить экран. Нижняя кнопка тоже работает.
**Энергосбережение Huawei**: часы могут закрывать Live Assistant в фоне (нижняя кнопка и встряхивания перестают работать, пока вы снова не откроете приложение). В Gateway, на странице часов Huawei, нажмите **PowerGenie: удалить** (если часы не позволяют, он отключается; **PowerGenie: восстановить** отменяет это). Если отладка по Wi-Fi остаётся включённой и вы в той же сети, Gateway сам снова запускает Live Assistant, когда часы его закрывают.

### Установка своих приложений на часы
На той же странице Gateway, раздел **Установить свои приложения на часы**: нажмите **📲 Выбрать приложение для установки…** и выберите скачанный файл. Подходят отдельные **APK** и наборы **APKS**, **XAPK** (вместе с файлами OBB) и **APKM**. Нужна отладка по Wi-Fi, как для Live Assistant. В поле ниже (раздел **Выполнить на часах**) можно ввести **команду adb** (например, `pm list packages -3`, чтобы увидеть установленные приложения) и нажать **Выполнить**: результат появится ниже, а **Скопировать результат** его копирует.

## Часы Wear OS (бета)
Live Assistant работает и на **часах Wear OS начиная с Android 9**, круглых и прямоугольных (Galaxy Watch, Pixel Watch, Oppo Watch, Mi Watch, TicWatch, Fossil…), в том числе на старых часах **Wear OS 2 и 3**, где Google Ассистент и WhatsApp больше не работают. Это то же приложение, что и на Huawei: голосовые вопросы с Gemini Live, графическая погода, Дом, Контакты, WhatsApp и Telegram через Gateway.
**Связь с телефоном**: сначала официальный канал Wear OS (Bluetooth, Wi-Fi или сеть, выбирает Wear OS), затем прямой Bluetooth. Gateway передаёт часам ключи и код канала: работает и вдали от телефона, если у часов есть сеть.

**Установка** — в Gateway Assistant нажмите **⌚ Часы Wear OS: установка и диагностика**. Сначала на часах включите **Параметры разработчика**: Настройки → О часах (на Galaxy *О часах → Сведения о ПО*) → несколько раз нажмите на **Версию ПО** или **Номер сборки**. Часы и телефон в **одной сети Wi-Fi** (точка доступа телефона тоже подходит). Затем выберите подключение:
- **Беспроводная отладка (Wear OS 4 и новее)**: Параметры разработчика → **Беспроводная отладка** вкл. (*Всегда разрешать в этой сети*).
  1. На часах откройте **Сопряжение нового устройства** (появится 6-значный код).
  2. В Gateway введите **только код** и нажмите **🔗 Сопряжение**: IP, порт подключения и порт сопряжения находятся в сети автоматически (кнопка **🔍 Найти часы в сети**; их можно также ввести в поля). После сопряжения кнопка становится зелёной, **Сопряжено ✓**: повторять не нужно.
  3. Нажмите **⬇ Скачать и установить Live Assistant**. Порт подключения меняется каждый раз, когда вы снова включаете беспроводную отладку: если команда не может подключиться, очистите поле порта, и Gateway найдёт его снова.
- **Отладка по Wi-Fi (Wear OS 2 и 3)**: Параметры разработчика → **Отладка ADB** и **Отладка по Wi-Fi** вкл. Введите IP часов (порт уже **5555**) и нажмите **⬇ Скачать и установить Live Assistant**; на часах разрешите отладку (**Всегда разрешать**).

Gateway устанавливает приложение, выдаёт разрешения (микрофон, датчики, обновления), исключает его из энергосбережения, передаёт ключи и открывает его. Каждая кнопка показывает шаги в окне (**Копировать**, чтобы отправить их тому, кто помогает).
На **Pixel Watch**, если после установки значок не появился в списке приложений, перезагрузите часы.
**Кнопка для открытия Live** — в настройках Live на часах (шестерёнка): *Долгое нажатие «Домой»: Live вместо ассистента Google*; на **Galaxy Watch Ultra** — **средняя (оранжевая) кнопка**: в настройках кнопок Samsung выберите **Нет приложения**, затем в Live нажмите **Изучить приложение кнопки** и нажмите кнопку один раз. Если сторож кнопки не активен, в Gateway нажмите **🔑 Выдать Live разрешения**.
**Уведомления телефона (только Huawei)**: Gateway → страница часов Huawei → **🔔 Уведомления телефона на часах**: выберите приложения (нажатием меняется: выкл. → *рядом*, по Bluetooth → *и далеко*, также через интернет, не более 40 в день). Если уведомление закрыто или нажато на часах, оно исчезает и с телефона. На Wear OS и Amazfit уведомления уже приходят от их собственных приложений.
**Telegram на часах** (Wear OS и Huawei): когда телефон не подключён по Bluetooth, через LTE или Wi-Fi вы читаете и отправляете Telegram (тексты, голосовые, фото) прямо с часов. Привяжите один раз, рядом с телефоном и с включённым *Прямым Telegram* в Gateway: настройки Live на часах → **Привязать Telegram (с телефона)**. Gateway сам подтверждает вход; при двухэтапной проверке часы спросят пароль. Часы появятся в Telegram → Устройства как *Live Assistant (orologio)*. Подключение открывается только при необходимости и закрывается через 2 минуты.
**Обновления**: на часах шестерёнка → *Проверить и установить*. На Wear OS 4 и новее приложение обновляется само (в первый раз разрешите *Установку неизвестных приложений*, затем подтвердите); на Wear OS 2 и 3 — через отладку по Wi-Fi, которая должна оставаться включённой.
**На той же странице**: *Отправить ключи на часы*; **DPI экрана** (*Сбросить* возвращает заводской DPI модели, например 340 на Samsung); **Установить свои приложения** (APK, APKS, XAPK, APKM); **Выполнить на часах** (команды adb); **Диагностика** часов (с моделью и версией Android).
**Кнопка**: на Galaxy Watch — Настройки → Дополнительные функции → Настройка кнопок → *Двойное нажатие* → **Live Assistant**. Для центральной кнопки Galaxy Watch Ultra мы готовим сторож кнопки: в Gateway нажмите **🔎 Изучить кнопки**, нажимайте кнопки часов 15 секунд и отправьте результат.

## Часы HarmonyOS (Watch 5, Watch 6, Watch Ultimate 2…) (бета)
Для часов Huawei на **HarmonyOS NEXT** (например, Watch 5, Watch 6, Watch Ultimate 2), которые не устанавливают APK, есть **Live Assistant для HarmonyOS**. У него те же функции, что и у других версий: голосовые вопросы с Gemini Live, погода, Дом, Контакты, WhatsApp и Telegram, будильники телефона, история. Устанавливается из **Gateway Assistant**, компьютер не нужен.
**Зачем нужен аккаунт разработчика Huawei**: HarmonyOS устанавливает только приложения, подписанные профилем с идентификатором ваших часов (UDID). Gateway создаёт ключ, сертификат и профиль с **вашим** аккаунтом, так же, как это делает DevEco Studio. Они остаются только на вашем телефоне и никому не передаются.

**1 · Аккаунт разработчика Huawei (один раз)**
1. Откройте https://developer.huawei.com, войдите со своим **Huawei ID** (подойдёт тот, что в приложении Здоровье) и пройдите **регистрацию разработчика** (бесплатно, индивидуальный аккаунт). Для проверки личности нужны действующий документ (удостоверение личности или паспорт) и банковская карта: дождитесь, пока регистрация будет одобрена.
2. В Gateway Assistant нажмите **⌚ Часы HarmonyOS: связь и диагностика** → **🔏 Файлы подписи для HAP** → **🔐 Автоматические профили: войти с аккаунтом Huawei (как DevEco)**.
3. Откроется браузер: войдите с аккаунтом разработчика и подтвердите. Браузер сам вернётся в Gateway, который покажет **✅ Вход выполнен**; кнопка станет **🔐 Аккаунт Huawei:** с вашим именем (нажмите, чтобы выйти).
Больше ничего не нужно: отладочные ключ и сертификат создаются автоматически при первой установке (или сразу кнопкой **🪄 Создать ключ и сертификат с аккаунтом Huawei**). У каждого аккаунта может быть не более 3 отладочных сертификатов (свой Gateway заменяет сам): если у вас уже есть 3, созданные в DevEco Studio, и Gateway сообщает об этом, удалите старый в AppGallery Connect (*Certificates, app IDs, and profiles → Certificates*).

**2 · Подготовьте часы**
1. На часах: Настройки → О часах → несколько раз нажмите на **версию**, пока не появятся **Параметры разработчика**.
2. В Параметрах разработчика включите **отладку (HDC)** и **отладку по Wi-Fi**: часы покажут **IP и порт** (например, 192.168.0.191:44911). Порт меняется каждый раз, когда вы снова включаете отладку.
3. Часы и телефон в **одной сети Wi-Fi** (точка доступа телефона тоже подходит).

**3 · Установите Live Assistant**
1. В Gateway: **⌚ Часы HarmonyOS** → **📲 Установить или обновить Live на часах**.
2. Введите **IP** и **порт** часов или нажмите **🔎 Найти часы в Wi-Fi** (если IP уже введён, порт находится за несколько секунд).
3. Нажмите **⬇ С сайта**. Gateway скачивает Live Assistant, регистрирует часы в вашем аккаунте, создаёт профиль, подписывает приложение, устанавливает его и открывает уже связанным с Gateway (код канала и ключи). Окно показывает каждый шаг до **✅ Готово**.
4. В первый раз часы попросят **разрешить отладочное подключение**: согласитесь.
Если на часах уже есть Live Assistant, подписанный кем-то другим, Gateway спросит, удалить ли его сначала (данные приложения на часах будут потеряны).

**Обновления**: Gateway Assistant показывает, когда доступна новая версия. Обновление делается так же (📲 Установить или обновить → ⬇ С сайта), с включённой отладкой по Wi-Fi; настройки и данные сохраняются.
**Связь с телефоном**: Live сам пробует прямой Wi-Fi (та же сеть), Bluetooth и, наконец, интернет (Wi-Fi или LTE часов) с кодом канала. Чтобы использовать Bluetooth: на часах ⚙ → **🔵 Проверить Bluetooth с Gateway** (разрешите доступ к Bluetooth).
**Live в фоне (бета)**: в ⚙ → **🌙 Live в фоне** часы получают оповещения о сообщениях по Bluetooth даже при закрытом приложении и каждые 30 минут проверяют будильники и сообщения. Расходует чуть больше батареи и требует сначала успешной проверки Bluetooth.
**Диагностика**: на часах ⚙ → Диагностика → 📤 Gateway; в Gateway она находится в ⌚ Часы HarmonyOS → **Диагностика**.
**Уже есть свои файлы подписи?** (для пользователей DevEco Studio): в **🔏 Файлы подписи для HAP** загрузите ключ **.p12** с паролем, отладочный сертификат **.cer** и профили **.p7b** (по одному на приложение, с UDID часов, который можно скопировать в **🛠 Инструменты hdc** → **📋 Идентификатор часов (UDID)**). Кнопка **🤖 Автоматические профили (AppGallery Connect)** использует официальные API, которые не работают с европейскими аккаунтами: в этом случае используйте вход с аккаунтом Huawei.
**Другие инструменты** (🛠 Инструменты hdc): **🔑 Отправить ключ Gemini и канал в Live**, команды на часах. Через **Выбрать HAP** можно установить и другие приложения HarmonyOS: если аккаунт Huawei привязан, Gateway подписывает их сам.

## С iPhone
Gateway Assistant существует только для Android: iOS не позволяет приложению всегда оставаться включённым, нажимать «Отправить» в WhatsApp, читать уведомления или передавать фразы Google Ассистенту.
**Live Assistant всё равно работает с iPhone**: вопросы к Gemini, голос, погода, новости, напоминания, громкость, яркость и фонарик.
Недоступно: команды умного дома Google, звонки по имени из контактов, отправка и чтение WhatsApp, резервный голос телефона.
- Пропустите шаг 1 и оставьте **Gateway Assistant → Код** пустым.
- Держите **приложение Zepp открытым в фоне** (не смахивайте его): если iOS его приостановит, часы скажут «телефон недоступен».
- Обычные звонки на часах работают через звонки по Bluetooth в приложении Zepp.

## Жесты запястьем (встряхивания)
Удобно при шуме вокруг или занятых руках. Включаются и выключаются в настройках приложения на часах (Huawei) и работают при открытом приложении:
- **Одно встряхивание, пока слушает**: сразу отправляет вопрос, не дожидаясь тишины.
- **Одно встряхивание, пока думает** (цвета крутятся): отменяет вопрос.
- **Одно встряхивание, пока говорит**: останавливает голос.
- **Одно встряхивание в ожидании**: новый вопрос (снова слушает).
- **Два встряхивания**: закрывают приложение. Сделайте второе после короткой паузы и **сильнее** первого, чтобы обычная повторная попытка не закрыла его по ошибке.
- **Кнопка «Стоп» (Huawei и Amazfit)**: с момента, когда начинает слушать, и до прихода ответа красная кнопка **■ Стоп** заменяет *Новый чат*: она отменяет вопрос, не отправляя его (или отбрасывает приходящий ответ), и команды этого вопроса не выполняются. Нажатие на центральную кнопку во время прослушивания сразу отправляет вопрос. Когда сообщение WhatsApp/Telegram или голосовое отправлено, появляется большая **зелёная ✓** с вибрацией и коротким звуком (без звука в режиме конфиденциальности); если не удалось — **красный ✗**.
Встряхивания не учитываются первые 2 секунды после открытия. Через **30 секунд** бездействия приложение само возвращается к циферблату.

## Что можно сказать
- «Какая погода завтра?», «Как сыграл Спартак?», любой вопрос (на вопросы о погоде часы также показывают **графическую карточку**: сейчас, ближайшие часы и дни)
- «Включи свет на кухне», «спокойной ночи»
- «Позвони Марио» (если Марио несколько, выберите нужного на часах)
- «Отправь Марио в WhatsApp: буду через десять минут» (нажмите **Отправить …**, чтобы подтвердить)
- «Прочитай мои сообщения WhatsApp», «ответь Анне: договорились»
- «Ответь в Telegram Луке: уже еду» (только в чаты Telegram с недавним уведомлением; «прочитай мои сообщения» показывает и сообщения Telegram)
- «Отправь голосовое Марио»: нажмите на контакт 🎤, говорите и нажмите ещё раз, чтобы отправить. Оно придёт как голосовое сообщение WhatsApp; на Huawei нужен Bluetooth с телефоном (или на странице Контакты **удерживайте WhatsApp** у избранного контакта: запись начнётся сразу)
- «Выключи завтрашний будильник», «останови будильник», «отложи будильник» (будильники **телефона**)
- «Запиши стоматолога в календарь на четверг в 10, напомни за час», «что у меня завтра?» (календарь **телефона**: в Gateway Assistant нажмите **Разрешить Календарь**)
- «Добавь молоко в список покупок», «сделай заметку: купить лампочки», «напомни завтра в 9 в Google Задачах позвонить Луке» (**Keep** и **Задачи**: Gateway вводит фразу в Gemini на телефоне; нужны специальные возможности Gateway Assistant и включённые расширения Keep и Задачи в Gemini)
- «Включи «Не беспокоить» до 7», «выключи «Не беспокоить»» (**«Не беспокоить» телефона**: в Gateway Assistant нажмите **Разрешить «Не беспокоить»**; действуют исключения, заданные на телефоне)
- «Напомни в 18:00 позвонить стоматологу», «будильник на 7», «сделай громче»

Команды на русском в основном понимает Gemini: если какая-то команда не срабатывает, напишите в группу Telegram, и мы её добавим.

**Быстрые команды и избранное**: в Gateway Assistant, в разделе «На часах: быстрые команды и избранное», добавьте кнопки с фразой для Ассистента (например, «Shield» → «включи Shield») и избранные контакты из адресной книги. На часах рядом с центральной кнопкой: значок **дома** (или стрелка **‹**) открывает **Дом** с вашими кнопками (они идут прямо в Ассистент телефона, без Gemini) и **«Не беспокоить»** для включения и выключения; значок **сообщений** (или стрелка **›**) открывает **Контакты** с вашим избранным и кнопками **WhatsApp** (скажите сообщение и подтвердите «Отправить») и **Позвонить**.

**Избранное и группы**: до **16 избранных** контактов и групп. Кнопками **+ Добавить группу WhatsApp** и **+ Добавить группу Telegram** вы выбираете группу: на часах у неё своя карточка с последним сообщением (и тем, кто его написал), пузырями и ответами. **Оповещения**: когда вам пишет избранный контакт (или в избранной группе), часы показывают имя и начало сообщения, а нажатие открывает чат в этом приложении. С прямым WhatsApp и Telegram оповещения приходят, даже если телефон не показывает уведомление.

**Режим конфиденциальности**: нажмите кнопку **микрофона** справа внизу от центральной кнопки: она станет зелёной **клавиатурой**: микрофон остаётся выключенным, а центральная кнопка открывает клавиатуру; напишите вопрос, и ответ придёт только текстом, без голоса. Нажмите ещё раз, чтобы вернуться к голосу. Для одного написанного вопроса можно также **удерживать** центральную кнопку. Нужны часы с Zepp OS 4 или новее.

## Изображения, счёт, формулы и графики (Huawei, Wear OS, HarmonyOS)
- **Проверенный спорт и новости**: перед ответом часы ищут в Google актуальные сайты («🔎 Ищу в Google…» на экране, несколько секунд). После ответа быстрая проверка сравнивает его с найденным: если есть ошибка, часы показывают и произносят **исправление**.
- **Карточка матча**: для матчей — команды, счёт, турнир и **авторы голов** с минутой (когда источники их указывают).
- **Изображения в конце ответа**: «Как выглядит Колизей?» показывает фото из Википедии; для новостей и спорта — фото статьи с **источником** (например, 📰 bbc.com). Пока оно загружается, вы видите «изображение загружается».
- **Формулы**: «Какая формула площади круга?» показывает правильно записанную формулу.
- **Графики функций**: «Построй график синуса x», «нарисуй параболу x в квадрате минус 4», «сравни x, x в квадрате и x в кубе» (до 3 кривых).
- **Увеличение**: нажмите на изображение, карточку или график, чтобы увеличить; поворачивайте **колёсико**, чтобы приблизить или отдалить.
- Изображения приходят после голоса, поэтому голос не прерывается.
- **Amazfit**: спорт и новости здесь тоже проходят через поиск Google, с карточкой матча и (с Live) проверкой ответа. В приложении Zepp, в Настройках, можно **выключить встряхивания запястьем**, если они срабатывают сами. Также показываются фото (Википедия и статьи), формулы и графики в конце ответов, кроме Bip и первого Balance (лёгкий режим).
- **Huawei Watch 3/4**: среди приложений часов есть также значок **Календарь**, чтобы сразу открывать события телефона.

## Если что-то не так
- Приложение Zepp → Live Assistant → **Диагностика**: показывает, что произошло с каждым вопросом. Она также приходит в Gateway Assistant (**⌚ Часы Amazfit: диагностика**): оттуда её можно скопировать или отправить файлом кнопкой **Поделиться файлом**.
- В Gateway Assistant **Журнал** показывает звонки, сообщения и команды.
- Gateway должен быть запущен («Gateway запущен ✓»), а батарея — без ограничений.
- **🐞 Сообщить о проблеме** в Gateway или голосом с часов («сообщи о проблеме: кнопка WhatsApp не работает»): сообщение доходит до разработчика вместе с журналом и диагностикой часов, тексты сообщений и номера скрыты. В первый раз спрашивается согласие. Gateway также сам сообщает о повторяющихся проблемах (не чаще раза в день для каждого типа).
- Кнопка Gateway **зелёная**, когда он работает, и **красная**, когда остановлен.
- **Анонимный подсчёт использования**: раз в день Gateway отправляет только случайный ID и версии приложений, без личных данных. Выключается кнопкой **📊 Анонимный подсчёт использования**.
